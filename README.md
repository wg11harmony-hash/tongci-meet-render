# 同词相遇 · Render 版

双人联机网页小游戏。各自输入词语，双方提交后同时揭晓；不同就继续，相同则达成默契。朋友使用浏览器即可加入，无需 ChatGPT 账号。

**部署操作见 [Render 部署指南](./Render部署指南.md)。**

也可使用 [Replit 部署指南](./Replit部署指南.md)，仓库已附带 `.replit` 启动和构建配置。

## 项目组成

- `src/App.tsx`：游戏界面，沿用紫色与薄荷绿设计。
- `src/styles.css`：响应式样式。
- `lib/game.mjs`：同词规则和房间状态处理。
- `server/app.mjs`：普通 Node.js HTTP 服务，同时提供网页和联机接口。
- `server/index.mjs`：启动入口，读取 Render 提供的 `PORT`，监听 `0.0.0.0`。
- `render.yaml`：Render Free Web Service 配置，已声明免费计划。
- `package-lock.json`：锁定依赖，供 `npm ci` 使用。
- `dist/`：交付压缩包内附带的已构建网页，可直接本地运行；Render 构建时会重新生成。

此版本使用 React + Vite 构建页面，运行后台只用 Node.js 内置模块。网页与接口共用一个地址；不依赖 Cloudflare D1、Sites 账号或 OpenAI 密钥。

## 本地试玩

需要 Node.js 24。压缩包已包含 `dist/` 时，解压后直接运行：

```sh
node server/index.mjs
```

打开 `http://localhost:3000`。用两个独立浏览器标签页模拟两个人：一人创建房间，另一人打开邀请链接加入。

## 修改和构建

```sh
npm ci --include=dev
npm run build
npm test
npm start
```

开发时可分别开两个终端：一个运行 `npm start`，另一个运行 `npm run dev`。Vite 会把 `/api` 请求转发给 `http://127.0.0.1:3000`。

## 联机规则

- 每个房间最多两人，提交后不能修改。
- 双方提交前，对方的答案不会发送到你的浏览器。
- 去掉首尾空格后逐字比较；不做同义词或 AI 判断。
- 双方准备后进入下一轮或重新开始。
- 座位凭证自动保存在当前浏览器标签页中；同一标签页刷新后可恢复。
- 结果可导出 PNG 长图。

## 免费版的数据行为

房间存在单个服务进程的内存里，最长有效 24 小时。服务重启、重新部署或休眠后，旧房间可能被清空，需要重新开房。结果长图可保存到自己的设备。

这适合两个人临时玩几局。如果以后需要长期战绩、多个服务实例或永久保留房间，再接入独立持久化数据库。

## 环境变量

| 名称 | 含义 | 默认值 |
| --- | --- | --- |
| `PORT` | 服务端口；Render 自动提供 | `3000` |
| `HOST` | 监听地址 | `0.0.0.0` |
| `NODE_VERSION` | Render 的 Node.js 版本 | 配置中为 `24.22.1` |

`GET /healthz` 是公开健康检查接口，正常返回 `{"ok":true}`。
